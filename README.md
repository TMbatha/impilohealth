The problem: Africa is short of about 6 million health workers. Patients with high blood pressure get treated at different clinics, and each nurse starts from zero because records don’t follow the patient.


How to run: python3 -m http.server 8000, then open localhost:8000/#demo → click Fill demo visit → Send.

How we kept tokens low (3 lines): plain HTML/JS with no framework and no AI inside the app; a handful of complete Copilot requests instead of back-and-forth chat; git and debugging done by hand in Terminal.
